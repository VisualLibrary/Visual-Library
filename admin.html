How to Add a Wallpaper
1

Upload to Cloudinary

Open Cloudinary → Media Library → correct category folder → upload image. Copy the Public ID from asset details panel.

2

Edit wallpapers.json on GitHub

Go to your repo → click wallpapers.json → pencil icon to edit. Add a new entry inside the wallpapers array:

{
  "id": "unique-slug-here",
  "title": "Wallpaper Title Here",
  "category": "marvel",
  "subcategory": null,
  "tags": ["tag one", "tag two", "tag three"],
  "cloudinary_id": "Your_Cloudinary_Public_ID",
  "resolution": "4K",
  "featured": false
}
3

Commit & Deploy

Scroll down → Commit changes → Commit directly to main → Netlify redeploys in ~30 seconds. Remember: batch changes into max 5–8 deploys/month to stay within credits.
